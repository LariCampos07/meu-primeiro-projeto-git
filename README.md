# Meu primeiro projeto
Projeto criado na aula de git e github por Larissa Campos

Comandos usados nessa tarefa
Para verificar se o git está instalado
$ git --version 

Para ver o que já está configurado
$ git config --list

Para configurar meus dados
$ git config --global user.name "Seu nome"
$ git config --global user.email "Seu email"

Para apagar a configuração dos meus dados
$ git config --global user.name "Seu nome"
$ git config --global user.email "Seu email"

Para conferir
$ git config user.name
$ git config user.email

Para inicializar um repositório
$ git init

Para verificar as mudanças
$  git status

Para enviar para area de staging
$  git add arquivo.algumacoisa

Para enviar ao repositório
$ git commit -m "mensagem" 

Para criar o repositorio principal
$ git branch -M main

Para vincular o repositório local com o repositorio online
$ git remote add origin https://github.com/meu-usuario/meu-primeiro-projeto-git-git.git

Para enviar os arquivos locais para o repositório online
$ git push -u origin main
